Colour Directions

Five ways to use more of the palette without leaving the accessibility rules. Every sample names its pairing and measured ratio.

The prototype has been using only the three pairings that work at any size, and all three involve Charcoal Black. The six large-text pairings have a size floor of 24px regular or 18.7px bold, which display type clears easily. The tint ramps add twelve more usable grounds. Nothing below is invented.

The boundary

Four Pairings That Can Never Carry Text

Shown so the limit is visible rather than assumed. These are backgrounds and shapes only, never type, at any size.

Deep Azure + Forest Green · 1.23:1
Bold Red + Deep Azure · 1.26:1
Gold + Fresh Green · 1.50:1
Forest Green + Bold Red · 1.02:1

Also excluded: Serene White on the Deep Azure 60% tint at 2.80:1, which the 2.2 chart recommends and which fails every threshold. That one is a defect in the guidelines, not a design choice.

Every colour traces to tokens.json. Large-text pairings are legal at 24px regular or 18.7px bold and above; below that only Charcoal pairings are safe.
