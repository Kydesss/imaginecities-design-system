# Examples — superseded by the Next.js app

`assessment-intro.html` and `assessment-flow.html` were the working prototypes. The
live implementation now lives in `apps/assessment/`, built from the same tokens.

They are kept because their comments record decisions and measurements that the app
inherits but does not restate: which pairings were rejected and why, the contrast
figures behind each colour choice, why the stage spectrum is not a progress bar, and
which copy is verbatim from the published build versus reconstructed.

**Do not develop them further.** Two implementations of the same screens will diverge.
`colour-directions.html` is not superseded: it is a reference of every usable pairing
in the palette with measured ratios.
